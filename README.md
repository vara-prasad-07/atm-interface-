# ATM Interface Project

This project simulates an Automated Teller Machine (ATM) using Python and the Tkinter library. It provides a realistic, interactive, and user-friendly graphical interface to mimic basic ATM functionalities. The project is ideal for understanding the mechanics behind ATMs and serves as a solid foundation for more advanced banking systems.

## Overview

The ATM Interface Project is designed with simplicity and practicality in mind. It allows users to perform standard banking operations, ensuring secure transactions and easy-to-navigate workflows. Whether you're looking to check your balance or perform deposits and withdrawals, this project covers the essential functionalities of an ATM.

## Features

### User Authentication
- **PIN Verification**: Secure login using a Personal Identification Number (PIN) to ensure that only authorized users can access their account.

### Balance Inquiry
- **Account Balance Check**: Quickly retrieve and display the current account balance for a transparent overview of your finances.

### Cash Withdrawal
- **Money Withdrawal**: Withdraw cash from your account with built-in validations to ensure sufficient funds are available before proceeding.

### Cash Deposit
- **Money Deposit**: Deposit funds into your account and update the balance in real-time.

### PIN Change
- **Secure PIN Update**: Change your account PIN securely to maintain account safety.

### Transaction Summary
- **Recent Transactions Display**: View a summary of recent transactions, allowing users to monitor their account activity easily.

## Technologies & Languages

- **Programming Language**: Python
- **GUI Framework**: Tkinter
